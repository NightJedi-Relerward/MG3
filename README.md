# MG3
## Devlog
1. In Unity, the default values are: float: 0.0; int: 0; bool: false; string: empty text
2. The Update() method gets called automatically by Unity once every frame as Unity engine detects Update() and executes it repeatedly.
3. For the TimerText class, it uses the timer by checking how much time is left and displaying that value on the screen. When the timer's Update() method runs every frame, it subtracts Time.deltaTime from timeLeft, causing the countdown to decrease over time.
